# Project_Tic_Tac_Toe
TIC - TAC - TOE

BY: Mishika Agarwal, Aayushi Nasa, Tanishq, Pushpangi, Bhumika

Tic Tac Toe Ultimate Edition is a console-based game developed using the C programming language. It offers two modes: Two Player Mode and Play Against Computer Mode. Players take turns marking X and O on a 3×3 grid, aiming to complete a horizontal, vertical, or diagonal line. The game automatically detects winners and draws, maintains a scoreboard, and allows users to play multiple matches

"Features Implemented"

Two Player Mode – Allows two players to play against each other. 
Computer Mode – Allows a player to play against the computer. 
Interactive Game Menu – Provides options to select game modes, view scores, and exit. 
Player Names – Allows users to enter their names. 
Random Computer Moves – Computer selects an available position randomly. 
Winning Detection – Automatically checks horizontal, vertical, and diagonal winning conditions. 
Draw Detection – Detects when all nine positions are filled without a winner. 
Input Validation – Prevents invalid positions and selection of already occupied cells. 
Scoreboard – Tracks individual wins, total draws, and total matches. 
Replay Option – Allows users to return to the main menu and play again.

"How to Compile and Run"
1. Save the C program as tic_tac_toe.c. 
2. Open the VS Code terminal in the project folder. 
3. Compile the program using: 
gcc tic_tac_toe.c -o game 
4. Run the program using: 
./game

For Windows, use: 
game.exe 

Make sure GCC compiler is installed and configured before compiling
